## Problem

The default model for the `opencode run` test framework needs to be changed from `ollama/qwen3.8:27b-256k` to `ollama/qwen3.8:27b-256k-gguf4`.

## Scope

The default test model is defined in `.opencode/tests-v2/default-model.sh` as `DEFAULT_TEST_MODEL` — the single source of truth. The change must update:

- `.opencode/tests-v2/default-model.sh` (the `DEFAULT_TEST_MODEL` value)
- `.opencode/tests-v2/with-test-home` (fallback model strings at the `seed_model_config()` and warmup smoke-test paths)
- `.opencode/tests-v2/AGENTS.md` (documentation references to the default model)
- `.opencode/docs/model-dependency.md` (documentation references)
- `.opencode/README.md` (documentation references)
- `.opencode/AGENTS.md` (documentation reference)
- Root `AGENTS.md` (documentation reference)
- Behavioral test scripts that assert the default model value: `test-2376-sc1-red.sh`, `test-2376-sc2-red.sh`, `test-2376-sc3-red.sh`

**Out of scope:** Any change to the test framework's model-selection logic, GPU/VRAM handling, or other model values beyond the default test model.

## Approach

Update the single source of truth `DEFAULT_TEST_MODEL` in `default-model.sh` to the new value, then propagate the change to all fallback model strings in `with-test-home`, all documentation references, and the behavioral test scripts that assert the default model value. The full spec content will be generated by the spec-creation pipeline after this issue is created.

## Impact

- **Risk:** Behavioral tests may fail if fallback strings or test scripts are not updated in lockstep with the source of truth. **Mitigation:** Update all locations in a single change and run the affected behavioral tests.
- **Risk:** Documentation drift if any reference is missed. **Mitigation:** Grep for the old model string across the repo to catch all references.
- **Dependency:** The new model `ollama/qwen3.8:27b-256k-gguf4` must be available in the local Ollama instance.
